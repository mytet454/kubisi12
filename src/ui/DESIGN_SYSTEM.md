# دليل نظام التصميم — سوق المستلزمات الطبية (Clinical Ledger Design System)

## 1. الرؤية والتوجه التصميمي (Clinical Ledger)

واجهة **"الدفتر الطبي السريري" (Clinical Ledger)**: هادئة، دقيقة، واضحة المسح البصري، ومصممة لتشبه تقريراً مخبرياً أو دفتراً محاسبياً مطبوعاً بعناية.
الهدف العملي يسبق الزخرفة: تقليل عدد النقرات لأمناء المستودعات والكاشيرية والمحاسبين ومالكي المكاتب الطبية في العراق، مع إظهار الإجراء التالي بوضوح، وتنسيق الأرقام والمبالغ بحيث يسهل قراءتها ومراجعتها بنظرة واحدة.

### قواعد الحذف والانضباط البصري
- **لا تدرجات لونية زخرفية (No Gradient Washes)** ولا خلفيات كريمية دافئة.
- **البطاقات للكائنات المستقلة فقط**: تُستخدم البطاقة (`16px` radius + layered shadow-as-border) فقط لمربعات المؤشرات (KPI Tiles)، وأقسام النماذج، والنوافذ الحوارية (`20px`). الجداول والقوائم تجلس مباشرة على الخلفية الأساسية (`#F3F6F7`) مع فواصل `1px`.
- **لا بطاقات داخل بطاقات**: يُفصل المحتوى بالمساحات البيضاء والفواصل الشعرية (`1px solid #D5DEE1`).
- **لا نقاط نبض زخرفية** ولا أيقونات إيموجي؛ أيقونات `Lucide` فقط بسمك موحد (`strokeWidth={1.75}`) ومقاس `20px` داخل عناصر التحكم.

## 2. منظومة الرموز اللونية والتباين (Color Tokens & Contrast)

تم فحص جميع أزواج الألوان وفق معيار **WCAG 2.1 AA** (≥ `4.5:1` للنصوص الاعتيادية، و ≥ `3.0:1` للنصوص الكبيرة وحدود عناصر التحكم التفاعلية).

| الرمز (Token) | القيمة (Hex) | الاستخدام |
|---|---|---|
| `--color-ink` | `#14323B` | النصوص الأساسية والعناوين |
| `--color-muted` | `#4F6670` | النصوص الثانوية والوصف وتسميات الحقول |
| `--color-placeholder` | `#597079` | نصوص التلميح داخل الحقول (`5.23:1` على الأبيض) |
| `--color-canvas` | `#F3F6F7` | الخلفية العامة للتطبيق ومنطقة العمل |
| `--color-surface` | `#FFFFFF` | سطح البطاقات والنماذج وجدول البيانات |
| `--color-surface-subtle` | `#EBF0F2` | خلفيات الصفوف المحددة ورؤوس الجداول |
| `--color-line` | `#D5DEE1` | الفواصل الهيكلية غير التفاعلية وصفوف الجداول |
| `--color-control-border` | `#748A92` | حدود الحقول والأزرار الثانوية وعناصر التحكم التفاعلية (`3.63:1` على الأبيض، `3.34:1` على `#F3F6F7` — معالجة لنقص تباين `#D5DEE1` كحد تفاعلي) |
| `--color-primary` | `#0B7285` | الإجراءات الأساسية، الروابط، وحلقات التركيز |
| `--color-primary-strong` | `#095C6B` | حالة التحويم والضغط على العناصر الأساسية |
| `--color-primary-soft` | `#E3F2F5` | خلفية التمييز النشط والاختيارات |
| `--color-success-ink` / `--color-success-bg` | `#1E6B45` / `#E4F4EA` | حالات الاعتماد، الرصيد الآمن، الدفع الكامل |
| `--color-warning-ink` / `--color-warning-bg` | `#7A4E00` / `#FFF1D6` | حالات التنبيه، قرب الانتهاء، نقص المخزون |
| `--color-danger-ink` / `--color-danger-bg` | `#B3261E` / `#FDE8E6` | حالات الإلغاء، الأخطاء، الفواتير المتأخرة، الحذف |

### قاعدة التمييز غير اللوني
لا يُعبَّر عن أي حالة باللون وحده أبداً؛ يجب أن يقترن كل مؤشر حالة بـ **أيقونة + كلمة واضحة** (مثل: `✓ معتمدة`، `⚠ قريبة الانتهاء`، `✕ ملغاة`).

## 3. الخطوط والهرمية والأرقام (Typography & Numerals)

- **عائلة الخط**: `'IBM Plex Sans Arabic'` (أوزان `400, 500, 600, 700`) مع بدائل `'Tajawal', system-ui, sans-serif`.
- **أحجام النصوص**:
  - **النص الأساسي (Body)**: `16px` بارتفاع سطر `1.7`.
  - **النص الصغير (Meta/Caption)**: `14px` (للتوضيحات والتواريخ الثانوية فقط، لا يُستخدم للمعلومات الجوهرية أبداً).
  - **العناوين (Headings)**: `18px` / `22px` / `28px` بأوزان `600–700` وارتفاع سطر `1.4` مع `text-wrap: balance`.
  - **الفقرات القصيرة**: `text-wrap: pretty`.
- **صرامة اللغة العربية**:
  - يُمنع تماماً إضافة `letter-spacing` على النصوص العربية لأنها تكسر اتصال الحروف.
  - لا يُستخدم الخط المائل (`italic`) ولا الأحرف الكبيرة (`uppercase`).
  - تنعيم الخط الأساسي على الجذر (`-webkit-font-smoothing: antialiased`).
- **الأرقام والعملة**:
  - **أرقام غربية (`0-9`)** حصراً مع `font-variant-numeric: tabular-nums` وخط `'Tajawal'` للأرقام لضمان اصطفاف العمود الرقمي بدقة في الجداول والمؤشرات.
  - فواصل الآلاف (`1,250,000`) في كل المبالغ.
  - لاحقة العملة `د.ع` بوزن أخف (`400`) ولون ثانوي (`--color-muted`) مع تثبيت حافة المحاذاة في كل صف.

## 4. الأبعاد، الظلال، اللمس، والحركة (Radii, Depth, Touch, Motion)

- **انحناء الزوايا (Border Radius)**:
  - عناصر التحكم (الأزرار، الحقول، القوائم): `10px` (`--radius-control`).
  - البطاقات: `16px` (`--radius-card`).
  - النوافذ الحوارية والأدراج الجانبية: `20px` (`--radius-dialog`).
  - العناصر المتداخلة تتبع المعادلة: `القطر الخارجي = القطر الداخلي + الحشوة`.
- **العمق (Depth)**:
  - البطاقات والقوائم المنبثقة تستخدم ظلاً طبقياً كحد (`--shadow-card`):
    `0 0 0 1px rgba(0, 0, 0, 0.06), 0 1px 2px -1px rgba(0, 0, 0, 0.06), 0 2px 4px rgba(0, 0, 0, 0.04)`
  - الحقول، صفوف الجداول، والفواصل تستخدم حدوداً حقيقية `1px`.
- **الشبكة واللمس**:
  - مقياس تباعد أساسه `4px`.
  - مساحة اللمس لأي عنصر تفاعلي `≥ 44px × 44px` (مع توسيع منطقة النقر عبر عنصر زائف `.hit-target-44` عند صغر الأيقونة دون تداخل مع العناصر المجاورة).
- **حلقة التركيز (Focus Ring)**:
  - كل عنصر تفاعلي يحمل `focus-visible:ring-2` بلون `--color-primary` مع إزاحة `2px` (`focus-visible:ring-offset-2`). لا يُزال التحديد (`outline-none`) أبداً بدون بديل مرئي.
- **الحركة (Motion)**:
  - الحركة استجابة لفعل المستخدم فقط؛ لا حركات دخول (entrance animations) لأقسام الصفحة ولا حركة عند التحميل الأول.
  - الأزرار تنضغط إلى `scale(0.96)` عند النقر خلال `150ms` باستخدام خصائص مسماة (`transition-transform`).
  - ممنوع استخدام `transition: all`.
  - احترام كامل لـ `@media (prefers-reduced-motion: reduce)`.

## 5. مكتبة المكونات (Components)

كل مكون يدعم الحالات: الافتراضية، التحويم (`hover`)، الضغط (`active`)، التركيز (`focus-visible`)، التعطيل (`disabled`)، التحميل (`loading`)، والخطأ (`error`).

1. **`Button`**: `primary | secondary | ghost | danger`؛ حالة التحميل تحافظ على عرض الزر ثابتاً دون اهتزاز.
2. **`Input` / `Select` / `Textarea`**: التسمية (`label`) دائماً **أعلى الحقل**، مع نص مساعد، ورسالة خطأ واضحة تحته.
3. **`MoneyInput`**: إضافة فواصل الآلاف لحظياً أثناء الكتابة، لوحة أرقام على الهاتف (`inputMode="numeric"`)، ولاحقة `د.ع` بوزن خفيف.
4. **`SearchableSelect`**: قائمة قابلة للبحث والتصفية مع تنقل لوحة المفاتيح (`ArrowUp/Down`, `Enter`, `Escape`).
5. **`SegmentedControl`**: خيارات متجاورة لتبديل الأوضاع أو التصفية السريعة بارتفاع `44px`.
6. **`DataTable` (نمط القوائم الموحد)**:
   - يجلس على الخلفية مباشرة مع شريط أدوات مثبت (`sticky toolbar`): بحث، رقائق حالة، نطاق تاريخ، مبدل الكثافة (`مريح / مضغوط`)، تصدير `CSV`.
   - رأس جدول مثبت (`sticky thead`).
   - النقر على الصف يفتح معاينة جانبية (`Drawer`) تحتوي زر `"فتح الصفحة كاملة"`.
   - إجراءات الصف في قائمة مرئية (`⋮`) لا تختفي خلف التحويم.
   - على الهاتف (`390px`): يتحول الصف إلى بطاقة نظيفة تعرض أهم قيمتين بوضوح تام ودون تمرير أفقي.
   - ترقيم الصفحات في الأسفل مع إجمالي السجلات.
7. **`StatusBadge`**: أيقونة + كلمة دائماً، بألوان الحالة المعتمدة.
8. **`Modal` و `Drawer`**: `Modal` بحواف `20px` للإنشاء والتأكيد؛ `Drawer` جانبي لمعاينة السجلات والتنقل السريع.
9. **`Toast`**: إشعارات `aria-live` متزنة بأيقونة ورسالة وزر إغلاق `44px`.
10. **`EmptyState`**: يشرح **ما هذه الشاشة** + **لماذا هي فارغة** + **زر إجراء واحد للبدء**.
11. **`Skeleton`**: قوالب تحميل ساكنة متطابقة الهندسة.
12. **`ConfirmDialog` و `Tabs` و `KpiTile` (`StatCard`)**.

## 6. هيكل التنقل، لوحة التحكم، والاختصارات (Shell & Dashboard)

- **الهيكل المكتبي**:
  - شريط جانبي أيمن قابل للطي إلى شريط أيقونات، مقسم حسب الوظيفة: `اليوم · المبيعات · المشتريات · المخزون · الحسابات · الإدارة`، ويعرض فقط ما تسمح به صلاحية الدور.
  - شريط علوي يضم: البحث العام (يُفتح أيضاً بـ `Ctrl/Cmd + K`)، زر الإجراء الأساسي `+ فاتورة بيع` للأدوار المصرح لها بالبيع، جرس التنبيهات بعداد غير المقروء، اسم المكتب، وقائمة المستخدم.
- **الهيكل المحمول (390px)**:
  - شريط سفلي بـ **4 وجهات رئيسية** وزر **`+` مركزي** يفتح لوحة الإجراءات السريعة (`فاتورة بيع · فاتورة شراء · سند قبض · سند دفع · مصروف`) مفلترة حسب الدور، مع صفر تمرير أفقي.
- **لوحة التحكم (للمكاتب)**:
  1. **صف "يحتاج تصرفاً اليوم"**: نواقص المخزون، قريب الانتهاء، ديون العملاء المستحقة، فواتير الموردين غير المسددة — كل بطاقة تفتح القائمة المطابقة مفلترة تلقائياً. عند تصفير الجميع يظهر تنبيه هادئ: `"لا يوجد شيء يحتاج تصرفاً اليوم"`.
  2. **بطاقات المؤشرات الست (KPIs)**: مبيعات اليوم، ربح الشهر، رصيد الصندوق، ذمم العملاء، ذمم الموردين، قيمة المخزون.
  3. **الرسوم البيانية الثلاثة**: دائري (المبيعات/التكلفة/المصاريف/الربح مع أرقام وتسميات مباشرة)، أعمدة المبيعات الشهرية، وأعلى 5 أصناف؛ كلها متوافقة مع RTL وبألوان النظام ومعها ملخص نصي عربي لقارئات الشاشة.

## 7. معجم النصوص والمصطلحات (Copy Glossary)

### قواعد التسمية الإلزامية
1. **الأزرار تبدأ بفعل يوضح النتيجة**:
   - ✅ `"حفظ الفاتورة"`، `"حفظ السند"`، `"حفظ المصروف"`، `"حفظ التعديلات"`، `"حفظ بيانات الموظف"`.
   - ❌ ممنوع: `"إرسال"`، `"تطبيق"`، `"موافق"`.
2. **مصطلح واحد لكل مفهوم في كل الشاشات**:
   - `فاتورة بيع` (وليس مبيعات / وصل بيع)
   - `فاتورة شراء` (وليس مشتريات / فاتورة مورد)
   - `سند قبض` (وليس استلام دفعة)
   - `سند دفع` (وليس صرف دفعة لمورد)
   - `مرتجع` (وليس إرجاع / مسترد)
3. **التمييز الصارم لكلمة "إلغاء"**:
   - **`رجوع`**: لإغلاق أي نافذة حوارية أو درج جانبي دون حفظ.
   - **`إلغاء الفاتورة`**: لإبطال فاتورة مرحلة وعكس قيدها ومخزونها فقط.
4. **صياغة رسائل الخطأ (ماذا حدث + لماذا + كيف تصلحه)**:
   - مثال: `"تعذر حفظ فاتورة البيع لأن الكمية المطلوبة تتجاوز الرصيد المتوفر (المتاح: 15). خفّض الكمية أو اختر وجبة أخرى."`
